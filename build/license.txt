2. SYSTEM PRIVILEGES & HARDWARE INTEGRATION
--------------------------------------------------------------------------------
Driver Hub interfaces directly with low-level Windows hardware subsystems:
(a) DriverStore Management: Driver packages are staged and injected into the
    Windows DriverStore using native Microsoft Windows utilities (pnputil.exe).
(b) Environment Variables: System and User PATH variables may be updated to
    integrate Google Android Platform-Tools (adb, fastboot) system-wide.
(c) System Restore Protection: For maximum safety, Driver Hub includes an
    automated Windows System Restore Point creator via Volume Shadow Copy (VSS)
    prior to executing driver store modifications.
(d) Administrator Elevation: Certain tasks (DriverStore injection, PATH registry
    broadcast) require Windows User Account Control (UAC) administrative consent.
